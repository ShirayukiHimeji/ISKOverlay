# ISKOverlay
My Repo for gentoo

> [!IMPORTANT]
> This overlay contains a customized `media-libs/libva-intel-media-driver` ebuild optimized for Intel Gen12 GPUs (Alder Lake / Xe-LP).
>
> Other packages in this overlay are not affected.
>
> Do not use this ebuild on other Intel GPU generations unless you review and adjust the `GEN*` CMake options accordingly.
